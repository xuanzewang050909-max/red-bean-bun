# 官方Base Overlay逐IP审查清单

由 `scripts/analyze_references.py` 从固定Commit的Tcl生成。这里列出每个实例的来源/版本、接口、时钟网络和处置理由；接口为源码连接中实际出现的端口，未连接的IP内部端口不据此推定。时钟栏是本层连接，频率由 `base_overlay_analysis.md` 的跨层映射解释。

资源成本未取得完整综合报告的实例统一标为‘待综合’，不能用此清单计算真实节省量。HLS局部估计见结构分析，不能相加后冒充最终布局布线占用。
