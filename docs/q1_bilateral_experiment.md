# Q1-r1：双侧暗线支持的预注册训练实验

本轮位于 **W1浏览器基线 → Q1质量筛选 → W2+Q2新PL实现**。Q1先在Windows离线执行，不依赖尚待补测的W1前台FPS；这不把W1标为完成，也不改变板上固件。硬件交付仍在Q1收益和W2/Q2实现验证之后。完整路线见[开发计划](browser_development_plan.md)。

本文件及[机器协议](q1_bilateral_protocol_r1.json)在候选数据集运行前冻结并提交Git。范围为原10张训练图、AH标注、256和512两个尺寸；程序只解码这10张图及其AH，不解码留出图/留出标注，不读取VK。原M0已公开的留出成绩是历史基准，本轮不查询新候选的留出表现。

## 假设与整数实现

现有背景差响应对单侧亮边缘敏感。检验候选C：中心线同时比左右侧线暗才保留原响应，之后复用原阈值28、十字闭运算、邻域计数和FOV。Gaussian/LUT/背景及后处理均不重新调参。它是项目的简化整数候选，借鉴[MF-FDOG研究](https://pubmed.ncbi.nlm.nih.gov/20202631/)中区分血管与非血管边缘的思路，不是论文算法复现或效果承诺。

对四个整数方向 `(dy,dx)=(0,1),(1,0),(1,1),(1,-1)`，沿中心线采样长度5或9；左右以法向 `(-dx,dy)` 位移，距离取 `{1}`、`{2}`、`{3}`、`{1,2,3}`。对角方向距离是网格步长，欧氏长度不同，不把它称为各向同性滤波。图像外坐标复制边界；评价FOV原样保持。

记中心及两侧灰度和为C/L/R。支持值 `min(L-C,R-C)` 使用有符号整数，最大绝对值2295；不除法、不浮点卷积、不先截断负数。平均差门限为0/1/2/4；0表示严格正值，其他表示支持值至少为门限乘线长。持续支持另比较“无”或“至少过半位置的中心同时比左右暗”，形成64个固定组合。方向/距离之间取或，同一方向的均值与持续支持必须同时成立。

先用合成常量、阶跃、细暗线、斜线、跨亮区暗线、断续孤点、边界和极值验证，并以独立逐像素标量实现核对。该测试只证明主机整数语义，不证明RTL、精度或板端速度。

## 评价与保护条件

所有候选报告逐图及macro Dice/IoU/Precision/Recall；原FOV与全图指标分开。额外区域都只在评价侧生成：

- 亮核：原Gaussian3(G)>=192；亮带：亮核15×15膨胀减亮核，限制在原FOV，覆盖整幅图，不使用手选中央裁剪。
- 细标注代理：AH中5×5计数≤10且3×3计数≤6的像素。只是预定义稀疏标注代理，不能当医学细血管宽度真值。
- FOV边缘：原FOV减其15×15零边界腐蚀；不会从评价分母删除。

进入Q2的必要条件同时满足：512训练macro Dice至少增加0.01；256降低不超过0.005；两个尺寸各自macro Recall降低≤0.02、每图Recall降低≤0.05、细标注代理pooled Recall降低≤0.03、亮带pooled Recall降低≤0.05；512亮带假阳性总数减少至少10%。这里是预先选定的工程筛选门槛，不是竞赛规定或临床标准。空GT区域召回记null并披露，不把空集合算作保护成功。

仅在全部门槛通过后按512训练AH macro Dice排序，再按较少滤波器、较短长度、较低门限、无需持续计数、候选ID消除并列。无候选通过就拒绝本轮直接移植PL，保存完整失败结果，为下一轮另立协议；不看留出/VK后回调，也不事后放宽门槛。FOV背景修正/亮区软惩罚作为后续单独消融，不能悄悄加进本轮。
