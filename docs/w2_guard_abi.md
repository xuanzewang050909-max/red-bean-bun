# W2帧参数与周期观测工作接口

2026-10-14。从已板测`retina_gaussian_guard.v`派生`retina_quality_guard.v`，原件不改。复用标准AXI GPIO承载控制和只读观测，不自写AXI总线、DMA或DDR。当前为待整合工作接口，不是已发布bit/HWH的能力。

## 控制与帧身份

32位控制字：bits1:0为stage0…3，bit2选择256（0为512），bit3选择C2（0为原A），bits7:4必须为0，bits15:8为阈值1…255，bits31:16为软件任务标签。高16位由guard记录并透传HLS，HLS计算不使用该标签。正式A/C2比较保持阈值28，C2惩罚28另为冻结常量。

第一个上游AXIS握手锁存全控制字，直到整帧结束保持；帧中写入其他值不会改变在途帧。空闲时非法阈值或保留位阻止输入握手/启动，若确有待发送输入则sticky配置错误置位；板端必须在提交DMA前拒绝非法参数，不能通过向真实板发送这种非法帧来测试。

原状态字bits13:0已收帧、bits27:14已发帧、bits28…30帧长/TKEEP/多余核心输出错误保留，新增bit31为非法配置拒绝。观测另有32位递增issued/completed序号，复位归零，满32位回绕；软件标签与原生序号都须匹配任务。

## 只读快照

另一个标准双通道AXI GPIO的输出通道选择页，输入通道读取32位值；地址需完整BD审查后确认。原控制GPIO与DMA地址不改。选择器整个32位参与匹配，未知页返回FFFFFFFF。

|页|内容|
|---:|---|
|0|身份52513231（ASCII RQ21），本ABI v1|
|1|bit0当前busy，bit1已完成快照有效，bit2非法配置sticky，bit3最近完成帧计时溢出；其余0|
|2|实际锁存的当前/最近控制字，含软件标签|
|3|最近完成帧的锁存控制字|
|4|最近完成帧原生32位序号|
|5|HLS首输入握手→最后一个核心输出首次有效的时钟差|
|6|HLS首输入握手→最后一个输出被下游接受的时钟差|
|7|首至末HLS输入接受期间，输入TVALID为0的周期数|
|8|核心输出TVALID且TREADY为0的周期数，包含末字等待|
|9|最近完成帧实际HLS输入握手字数|
|10|最近完成帧输出握手字数|
|11|已启动帧原生32位序号|
|12|计时器位宽，生产必须为32|

页3…10在最后输出握手同时提交，此前保留上次已完成快照。多寄存器读前后检查页4相同、有效且对应本次任务；单工作者仍不允许下一任务先启动。页2是活动参数，不能冒充页3完成参数。计时从核心的输入握手开始，比guard接收首字晚，不能混作DMA起点。

周期差包含核心内部/流接口停顿；页5排除末字额外下游等待，页6包含。两者都不是无阻塞理想计算量；输入空等只在尚未接收完整核心输入时计算。计数器饱和并标记溢出，不能回绕给出虚假短延迟。实际秒数需由最终已验证核心时钟换算；尚未测得任何真实板核心延迟或纯DMA时间。

## 验证边界

`tests/retina_quality_guard_tb.sv`使用明确标注的FIFO核心替身，独立按握手时刻统计周期，验证控制锁存、快照、帧标签、计时、饱和、非法配置拒绝、TLAST/TKEEP与在途复位。正常32位与仅测试使用的8位计数器同时接受相同流，强制覆盖饱和。它只证明帧适配与观测单元，不证明C2算法或HLS流水线无死锁。

后续必须连实际生成的`retina_quality_hls` RTL，覆盖256/512、A/C2、动态T边界、有限FIFO/长背压/帧中改参/复位、原A28兼容，以及完整100MHz实现与官方reset仿真。配对bit/HWH和PS驱动审查完成后，才提供新的板测Notebook与浏览器包。
