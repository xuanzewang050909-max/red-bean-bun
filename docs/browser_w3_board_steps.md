# W3：浏览器接入 C2、真实阈值和硬件计时

前置W2+Q2已通过80帧、13,303,808字真实DMA复核。本包复用同一bit/HWH，无HDMI；旧发布保留。本次是交互集成验证，正式性能/全数据集质量/长时稳定仍在W4+Q3/W5进行。

1. 在 Jupyter **Running** 页关闭已经成功完成的旧测试内核。旧浏览器服务若仍运行，先在其启动Notebook正常结束服务，看到 `BROWSER_SERVICE_CLOSED_IDLE` 再关闭；FAULT内核保留。
2. 新建文件夹 **retina_browser_w3_r1**，上传 `D:\PLD\retina_fpga\build\deploy\browser_w3_upload_r1` 中的全部两个文件：**browser_w3_c2_r1.zip**、**browser_w3_start.ipynb**。ZIP不用手动解压。
3. 打开 **browser_w3_start.ipynb**，依次选中前三个代码框按 **Shift+Enter**。等当前框变成 `In [数字]` 且无报错，再运行下一框。

|代码框|完成标志|
|---|---|
|1：校验并展开|`PACKAGE_BYTES_PASS`|
|2：检查环境、保留端口|`BROWSER_PRECHECK_PASS`|
|3：加载一次并启动服务|`BROWSER_SERVICE_READY`|

4. 打开 **http://192.168.2.99:8090/**（IP变化时用第3框打印地址）。页眉应为 **W3**，有 **PL算法 A/C2** 和可编辑阈值。依照下表设置，每行点击一次 **运行 FPGA**；等待完成、任务ID更新、实际回读参数与所选值一致，再进行下一行。

|次序|图像|尺寸|算法|阈值|PL处理模式|
|---|---|---:|---|---:|---|
|1|im0001|512|A|28|最终掩膜 · 模式3|
|2|im0001|512|C2|28|最终掩膜 · 模式3|
|3|im0001|512|C2|40|最终掩膜 · 模式3|
|4|im0001|512|A|28|最终掩膜 · 模式3|
|5|im0002|512|C2|28|最终掩膜 · 模式3|
|6|im0001|256|C2|28|最终掩膜 · 模式3|

|8|im0001|256|C2|28|输入旁路 · 模式0|

前两行用同图同阈值比较A/C2，建议各保留一张截图；C2应减少部分亮区误检，但不会完全消除。第3行只是验证真实阈值生效，不是推荐把40作为正式阈值。第4行应恢复A28结果。第8行只有原图、无分割分数是正常行为。

5. 再选 **im0001 / 512 / C2 / 28 / 最终掩膜**，点击 **连续运行20帧**。保持该网页在前台，不切换标签或修改参数。结束后保存包含四图、PL核心、DMA、完整推理、浏览器延迟/FPS及回读参数的截图。
6. 返回启动Notebook，依次运行最后三个代码框：

|代码框|完成标志|
|---|---|
|4：查看状态|`IDLE`，`completed`至少28，`pending: 0`，无错误及保留缓冲|
|5：打包记录|`BROWSER_RECORDS_READY`；生成 `browser_w3_session_bundle.zip`|
|6：安全结束|`BROWSER_SERVICE_CLOSED_IDLE`|

7. **Ctrl+S** 保存；通过 **File → Download as → Notebook** 下载运行后的 **browser_w3_start.ipynb**。回文件列表下载 **browser_w3_session_bundle.zip**。两者下载完成后反馈“已下载”并发截图。

此轮8次手动+20帧连续，共28个新任务。PL窗口来自RQ21周期且含流式等待；DMA事务与PL重叠；完整推理包括配置、分配、DMA和CPU快照；请求→绘制与FPS用浏览器单调时钟。纯DMA搬运仍需后续独立实验，不相减伪造数值。连续20帧为诊断组，非正式性能验收。

遇到红色报错、FAULT或一分钟没有新进展就停止，保留输出，不重复运行、重载FPGA或关闭失败内核。网页停止按钮仅停止后续请求，不取消在途DMA。亮区效果、PS编码速度和浏览器FPS分别评价，不以一项改善冒充其他项已通过。
