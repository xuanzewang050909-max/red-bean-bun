## 原因与现有计划的缺口

当前响应是 `clip(4*(15×15背景均值-增强灰度),0,255)`。亮核通常比背景均值亮，响应被裁为零；它却会抬高邻近窗口的背景均值，使旁边较暗的区域得到较高响应。该操作没有血管横截面、方向一致性或亮斑边缘辨别能力。闭运算和“3×3至少两个候选”不能清除大片或连接到血管上的误检。外侧眼底轮廓也有相似的强边缘问题。

原 [M0报告](../results/m0_stare_2026-10-11/evaluation_report.md) 已记录视盘、病灶和边界假阳性；原 W4 只有总体评价，没有针对该错误的修正方案。W2 可调阈值是交互能力，不能被描述为已经解决此问题。为说明代价，仅在本训练图离线把 T 从28改为48，AH Dice 从0.490929降到0.334790，Recall 从0.583103降到0.285722，示例带仍有2,219个两套标注均不支持的候选。这不是新正式阈值选择，也不更改当前 PL 固件。

原离线方向算法B取 `max(A响应,方向响应)`，并未作为非血管否决条件；其训练结果更差。因此不能直接启用旧B并声称解决。

## 新增 Q 阶段：优先检验对称暗线与边缘抑制

保留当前 A4/M0-A-28 作独立基线，另建候选 C；原发布、驱动、DMA/DDR及浏览器服务复用。先在原训练组 AH 离线筛选，再定点/RTL验证、真实板测。浏览器不会隐藏亮区、PS不会先改 mask 再把它标成PL输出。

1. **方向与双侧支持。** 对若干方向、宽度读取中心线及两条平行侧线，先试长度5/9、侧距1/2/3的有限组合。设等长中心/两侧的灰度和为 C、L、R，构造 `S=min(L-C,R-C)`，保留中心同时比两侧暗、沿方向有持续支持的候选。单侧亮、单侧暗的阶跃边缘较难通过此判断。它是拟验证的整数近似，不是完整复现文献算法，更不是已证实有效的参数。
2. **亮区附近置信处理。** 首选上述对称性判据；若仍有局部误检，再试用 RGB/G 生成的亮区与局部梯度作软惩罚，并逐项消融。不得把亮区连同外沿一刀切清零：真实血管可经过这些区域，细血管、分叉和血管中央反射也可能受损。亮度规则只可用输入图像，不可用 GT。
3. **FOV轮廓单列验证。** 检查背景窗口/双侧采样跨越 FOV 时的影响，优先试有效邻域支持或输入FOV感知的背景估计。评价分母保持原 FOV，新增排除的有效区域中真实血管必须计入漏检；不能扩大评价腐蚀圈来提高分数。与中央亮区改进分开消融。
4. **谨慎清理。** 分别检查阈值前、形态学后假阳性和漏检；不能用整连通分量删除，因为误检可与真实血管相连。避免为了图像干净而消掉细血管。

优先复用已审查的 2017.4 `hls::Filter2D`、行缓存、定点比较与既有标准接口。共享窗口/多方向的实际 BRAM、DSP、LUT、背压和冲刷成本需先核算；资源不合适或训练无益时拒绝移植，不预报提速和精度收益。

研究依据：[Zhang等，MF-FDOG，2010](https://doi.org/10.1016/j.compbiomed.2010.02.008) 说明普通匹配滤波也响应非血管边缘，提出结合一阶导数区分对称血管与非对称边缘；[Lázár与Hajdu，方向响应相似性与对称约束滤波，2015](https://doi.org/10.1016/j.compbiomed.2015.09.008) 针对视盘/亮区边缘假响应研究对称约束。我们据此提出适合现有定点通路的候选，文献成绩不能作为本项目成绩。
