# C7复用与运行边界

本模块是医学处理扩展。基础PS/DDR/AXI DMA、AXI GPIO、时钟/reset与PYNQ驱动沿用已实测的A4派生结构，未重写基础IP，不增加HDMI。`references/`和工具安装目录不改；最终实现前后HWH参数/地址/连线须由 `check_q4d_hardware.py` 比较。

空间窗口继续使用Vivado HLS 2017.4原始 `hls::filter_opr`、复制边界及行缓存。派生 `retina_detector_c5.cpp` 只去掉旧C5顶层外部接口声明并改名，让它成为新dataflow内部阶段；原A/C2/C5运算不变。新C7从同一次输入原绿色分支取36项整数局部特征并在PL执行固定判别树；C5分支保留原增强和对照。两分支由FIFO对齐，最终C7仅替换打包结果的掩膜和响应分数字节，原图/增强字节仍来自同次PL处理。

特征包含3/7/15局部均值、15区域极值、5/9/15四方向暗线与5/9双侧支持/不平衡/中心对照，均限定于17×17邻域。全数定点，平衡归约只改变硬件计算顺序，16位和无溢出。固定8棵深度6树的常量来自原训练AH；阈值用floor后的整数比较，叶分数0…255，8棵平均按整数半向上取整。CPU训练和独立参考只在主机，板端包不包含分类器或原始标注驱动推理。

多特征集合分类器方向参考[Fraz等2012原始论文](https://pubmed.ncbi.nlm.nih.gov/22736688/)，本项目不是该论文精度复现，特征、树规模、整数定义、数据拆分和限制以本仓库冻结协议为准。冻结后质量分别报告训练重代入/复用留出×AH/VK；不将旧基准称新外部验证。

RQ71控制兼容旧bit0…4并新增bit5：C7必须同时置C2/C5前置位；bit6/7仍保留。每帧参数锁存、tag/sequence/周期回读由派生guard实现，不能只显示请求值。浏览器C7允许最终掩膜/旁路；旧中间阶段仍由A/C2/C5提供。C7推荐112是新评分阈值，与旧28含义不同，切换算法明确重置推荐值。

Python只负责输入/DDR/DMA/配置、读取、指标、PNG、浏览器服务及导出；人工血管标注仅在PS评价路径，不用于算法输入。浏览器颜色叠加和透明度只改变显示，实际掩膜必须逐字来自DMA。发布构建强制新bit/HWH、实际生成RTL验证、实际布局布线时序、reset和字节配对，主机替身测试永不算作板测。
