# W5a：可信C7前台长时间稳定性（待真实板测）

W4c已独立核验619次传输、101,253,137字一致，一次加载、安全关闭。无需重跑。用户没有功耗测量设备，整板实际功耗记NOT_MEASURED_NO_INSTRUMENT；原Vivado片上2.572W估计不是实测。

本轮复用原可信C7、官方DMA/GPIO、DDR和浏览器图像解包/叠加。新增的是有界稳定性调度、结果存储去重和回收核验，没有新医学算法或CPU分割后备。真实板状态BOARD_NOT_RUN。

## 当前轮次与后续边界

W5a：1000次新PL任务、至少30分钟、前台连续显示、每10帧切图/参数、20图/256和512/C7最终模式T96/112/128、每帧资源和身份记录。图像/尺寸/阈值组合是预先固定的100个十帧块；不是所有参数的笛卡尔积。每个新任务起点至少间隔2秒；约34～50分钟，较慢时可能更长。这是限速稳定性，不是最高FPS测速，不替代已经归档的W4b正式速度。

W5b另轮：手动模式/阈值边界、忙队列/重复请求、客户端断开重连、无GT展示、导出与安全恢复等覆盖审查。不能将W5a单轮提升为完整W5通过。1000帧没有实际触发计数器回绕；沿用旧仿真覆盖，不伪称本轮实测了回绕。质量优化仍按用户要求后置，C7现有亮区/细血管局限不变。

## SD卡与证据

每帧仍执行真实PL，先保存新的实际NPY和PNG，随后按SHA256核对文件内容，只有字节相同才以硬链接共用存储。每帧独立的参数、时间、回读、状态、文件身份和前台观测保留；相同配置若出现不同的实际输出，立即停止并保留异常原始帧。不是复用旧帧代替运算，也不修改掩膜。

同一文件系统需要支持硬链接（在加载前测试）。起始空闲至少1.5GiB，运行中低于512MiB即在下一次DMA前停止；导出还会计算独立所需空间。去重通常大幅减少重复数组/图像，实际占用需板测；不保证任何异常无限增长仍可完成。每帧记录RSS、MemAvailable、CmaFree和SD剩余。冻结资源门槛为第100帧后RSS增量不超过96MiB、全程MemAvailable至少48MiB；这是本轮可执行门槛，不等价于证明没有任何内存泄漏。

ZIP保留JSON、CSV、按内容存放的原始NPY/PNG和逐任务引用。所有任务的实际数组都可完整还原和核验，不做抽样删证据。离线核验会逐帧检查实际数组/图像、独立整数参考、AH/VK、原GPIO快照、DMA状态、双端单调时钟、事件和CSV；候选质量、完整W5与功耗仍分别报告。

## 回收与还原（电脑端）

原件复制到新的`build/board_results/c7_w5a_<日期>`后：

```powershell
& 'D:/PLD/retina_fpga/.venv/Scripts/python.exe' -X utf8 -B scripts/verify_c7_w5a.py <结果ZIP> <运行Notebook> <新的核验目录> --release build/deploy/c7_w5a_stability_r1
```

需要常规逐任务NPY/PNG文件树时，运行`python scripts/restore_c7_w5a.py <结果ZIP> <全新输出目录>`。该工具只核验和还原字节，不是板测验收；同样用硬链接保留空间，已有目录拒绝覆盖。
