## 已有机制的具体局限

- C5保留现有C2像素时，任意尺度/方向存在宽松双侧支持即可通过。局部暗纹理和亮边旁的暗带仍可能符合这个条件；增加方向数量本身不能证明可以区分。
- C5新增像素仍要求原种子两端和1–3像素有支持短桥。im0001/512 AH骨架覆盖只从64.31%到65.48%，更长或整段漏检不是浏览器绘图缺线，不能只延长补线距离解决。
- 既有D1研究显示原绿色小尺度有可用细节，但单特征全局阈值精确率不足；r4梯度并集曾恢复真血管也带回大量误检。这两条已有失败结论仍有效，不重跑旧阈值网格，不宣称直接使用某个特征就能修复。

## 下一研究的边界

1. **检测与剔除分开。** 保留当前较宽血管通路，另研究原绿色、尚未经LUT饱和的小尺度暗脊证据，用于C5未检出的细分支。输出必须具有局部截面与沿走向的联合支持，不能仅并入低阈值背景响应。C5已有像素是否留下与新像素能否加入分别设判据和消融。
2. **区分持续暗线和亮边。** 在同一局部窗口联合考察中心、双侧及更外侧灰度变化与沿走向支持，比较真正暗谷截面和单侧亮度跳变；保留跨亮区血管作为召回检查。具体规则先做合成亮边/暗线/弯曲/分叉测试和PL代价审查，再冻结有限协议。不能只把亮区及周边清零，也不能用GT提供在线亮斑掩膜。
3. **检测先于连接。** 先评新分支本身的真阳性/假阳性与骨架覆盖。只有检测确实恢复有效细节后，才研究方向一致的有界连接；含无连接消融，验证弯曲、相邻平行血管、分叉和错误端点。避免迭代无约束生长或整图膨胀让掩膜“看上去连续”。
4. **控制实现成本。** 先检查既有厂商窗口/行缓存及定点算子的复用方式和当前C5的LUT/BRAM余量，再确定有限尺度与方向。若所需资源超限，评估共享替代当前C5证据模块，不能假设可无限叠加。必须保存新的实际综合、布局布线、背压/复位/多帧结果，不能借用C5的资源与3.039ms作为新算法数据。

起始约束是先冻结候选数、窗口、阈值、整数范围、边界处理和评分规则再训练评分；该冻结已在16dec32完成。原10训练AH按图做内部划分，报告内部复用局限，不伪称独立新验证。最终C7选择在6c13730冻结，四算法160帧板测协议在2a8b353冻结，之后全20图/AH/VK仅作固定评价，不反向选参。
