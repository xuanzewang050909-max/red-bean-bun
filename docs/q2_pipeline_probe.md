# W2+Q2完整图像流水线工作副本

2026-10-14。在独立C2窗口探针之外，从已板测A4创建 `hls/retina_quality_hls.cpp` 工作副本。原A4源码、固件、驱动和W1发布不改。此副本未构建板级Overlay，不能上传为完成的浏览器算法。

## 受控增量

Gaussian3/LUT、背景BoxFilter15、复制边界、原响应A、FOV、十字零边界闭运算、3×3计数和四字节输出沿用A4。增强E复制到厂商共享19×19支持窗口；原响应载荷用独立8192×64位FIFO等待同一帧的支持结果，再选原A或冻结C2响应。原输出response字节在C2模式表示饱和扣减后的响应。该FIFO是容量候选，必须由完整生成RTL背压测试确认，不能用Csim证明。

工作控制字：bits1:0为stage 0/1/2/3，bit2为256（否则512），bit3为C2（否则A），bits15:8为阈值1…255。其他位暂不赋予功能；阈值0必须由未来W2控制器拒绝。`ap_none`控制端要求调用者全帧保持稳定，新首输入锁存/真实回读/帧ID及计时观测尚未接入。该位域不是已发布服务的能力声明。

`stage=0`仍输出原B/G/R/FOV32位字；其他stage依次为原G/增强E/所选阶段mask0或255/所选响应。C2的惩罚28固定，动态分割阈值T独立；正式质量对比仍T28。原A模式T28必须匹配冻结原算法输出，不因为新增窗口而更改A定义。

## 本步实验协议

首次工具运行前提交工作副本/测试台/Tcl及原A4→新副本受控diff。独立C++直接坐标参考先核对原A4的16帧全链兼容用例，再8帧C2/阈值1、27、28、29、255/旁路与FOV用例，总24帧2,949,120字。参考直接计算九点高斯、225点背景和20对9点侧线，未调用新HLS functor。仅合成图案，不读医学GT或评价留出。

工具生成的RTL与综合估计归档，不把这些数值当完整Overlay资源/时序或真机速度。新核心必须继续完整有限FIFO、帧配置锁存/已生效回读、复位/背压/多帧与原61板测用例回归；完整100MHz实现/HWH/bit配对审查后才交付新上板包。原算法A与候选C2都需真实DMA全字验证。W1前台FPS补测已于2026-10-14归档，无需重做。

完整规范见[Q2 PL规格](q2_quality_pl_spec.md)，独立窗口复用审查见[Q2复用审查](q2_hls_reuse_audit.md)。
