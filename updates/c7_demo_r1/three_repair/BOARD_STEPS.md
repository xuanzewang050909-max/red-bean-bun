# 三图板测操作说明（本任务尚未授权执行）

本包只表示离线准备完成，BOARD_NOT_RUN。另行获得针对本版本的板测授权、确认旧现场已经保存且板卡空闲后，再进行以下硬件步骤。不要运行旧任务第二段，不删除旧ATTEMPT标记，不在原故障内核加载新位流。

1. 后续手动操作时，在Jupyter中新建独立文件夹`c7_three_image_completion_r1`。上传本次`C7_ThreeImage_Completion_Board_r1.zip`和`C7_ThreeImage_Operator_r1.ipynb`。与原目录隔离，不覆盖旧文件。
2. 打开新Notebook。第一格只解压；若提示payload已存在，先核对目录，不通过删目录强行重跑。第二格仅核对包内SHA，必须显示`OFFLINE_PACKAGE_VERIFIED`及6项顺序：noise_0、noise_1、noise_2、im0004、im0291、im0319。这两格不会加载硬件。
3. **仅在另行授权后**，人工确认旧现场已保存、可安全加载本包，再将第三格`AUTHORIZED=False`改为`True`，运行一次。不要Run All。此格会加载匹配的50MHz独立精修overlay，先小工作区三配置，再三张512实际输入；不会重建或重载可信C7原overlay。
4. 原C7旧mask已随归档输入明确封存；新PL实际计算平滑、响应、候选、传播、清理及并集。参考工作区只用于运行后的核验，不传给PL。profile0/1/2是显式专项参数，不是每像素答案。
5. 出现异常、数值差异、超时或页面断连时立即停止。不要再点执行，不重启/复位，不清理缓冲，不删标记重试。内核可响应时导出失败包；不能响应时先保留页面和已有文件。
6. 成功显示`BOARD_NUMERIC_MATCH_PENDING_HOST_REVIEW`后，运行显示格查看三图真实PL前后对比，再运行最后导出格，下载`three_image_board_results_r1.zip`供开发电脑独立核验。不要把板端自检替代最终主机核验。

目前测试网页和原C7发布物均未改动。此包不会自动接入现有网页，也不会修改板端时钟到临时频率。真实时钟应为50MHz，运行时只读检查实际配置，不通过改频凑通过。响应时间没有正式上限，LATENCY_TARGET_UNSET。
