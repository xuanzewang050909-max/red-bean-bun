# 单张 im0324 血管补标

本目录是独立单图路线，不调用旧多图优化、模型、标注或板卡。默认处理现有 512×512 原生 C7 输入中的 RGB，原 M7 作为只增不删的旧标注。

软件已冻结 v08：整数二项平滑保留 Q4，8 方向 × 3 宽度的双侧暗线响应，中心脊线与正交响应过滤，固定 16 次同步邻域传播，9×9 支持量筛选，最后与旧 M7 合并。参数不含图名、GT、坐标表或人工路径。方向几何常量是通用有限窗口偏移，不是图像答案。

`results/single_repair_r1/frozen_algorithm.json` 固定算法、边界、单位和源身份；`input/source_manifest.json` 固定来源、真实 C7 会话以及显示坐标映射。所有旧标注保留；淡小血管和交汇处仍有不确定性，不使用独立 GT 指标宣称通过。

软件整数参考在 `software.py`。C/HLS 实现在 `hardware/repair.cpp`，仅在 `hardware/geometry.hpp` 使用已冻结的方向偏移。`test_integer.py` 实际比较整图全部中间值、结果和保护字；`rtl_prepare.py` 生成真实 HLS RTL 测试，`integration_test.py` 连接本次生成的实际控制/DDR fabric。

工作区为 6 个 uint32 平面，每平面 H×W 字：输入、Q4 平滑/FOV、方向响应、活动0、活动1、最终结果。输入字低24位RGB，高位24是FOV，位25是旧 M7。最终字 bit0最终、bit1新增、bit2不确定。最大帧 512×512，总有效工作区6MiB，额外32字保护区；DDR地址按字节，核心内部偏移按32位字。输入平面只读，所有工作平面由有界 PL 阶段覆盖写入。图像和旧掩膜不存入ROM。

阶段命令固定为 0、1、2、16次3、4，共20次。命令0建立新状态，1响应，2种子，3同步传播，4支持量及合并。非法阶段/容量/尺寸拒绝，无越界写。仅阶段4返回0且全链成功时主机才接纳输出。

板测脚本 `board_run.py` 及 `board/` 默认离线，显式人工调用 `start` 才可能导入 PYNQ。本轮没有运行该入口。继承原已修复的记录工具，关键硬件动作前不阻塞打印。任何新错误停止、不复位、不重载、不释放保留缓冲、不自动重试。

实际物理门禁通过前不得发布 bit。没有板测输出不得将此路线标成板上通过。原 C7 overlay 和时钟不改。
