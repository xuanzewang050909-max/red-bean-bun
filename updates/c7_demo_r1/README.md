- 单图/三图均使用图像驱动的有限窗口暗线响应、强弱证据、有限传播及旧mask并集；新增识别、筛选与合并在PL执行，PS负责调度与展示。没有把最终mask预存到PL播放。
- `single_repair/`：im0324的整数参考、HLS、复位修复、集成与独立板测核验程序。
- `three_repair/`：其余三图共用核心及显式profile，整数参考、HLS、集成、物理门禁与独立板测核验程序。
- `three_web/`：四图原版/改进版网页、服务和记录核验；`three_web/demo/`：可重复启动的薄包装。
- `public_payload/`：本地封存展示ZIP的非数据子集，含实际配对bit/HWH、寄存器定义、时钟契约、驱动和网页。所有复制文件保持原字节；两份补标overlay为50MHz，原C7为100MHz。
- `physical_reports/`：原构建的实际最终时序、资源、约束及DRC报告；`results/`：既有软件/物理/板端核验和本次展示主机测试记录。历史报告中的NOT_RUN是各自当时状态，不改写为事后PASS。

## 使用及复现边界

[Notebook](demo_release/C7_Demo_r1.ipynb) 和 [操作步骤](demo_release/展示操作.md) 与本地 `C7_Demo_r1.zip` 配对。ZIP SHA256：`2f8c1a21b542bce6eb2370d03610c45805cf510a559a3c6a5f73c06add26c053`。

由于STARE数据再分发许可尚未确认，此仓库不包含原图、标注、派生mask/数组/截图及完整含数据ZIP。`public_payload/`故意不是可直接运行的完整包；原完整manifest不被删减，缺少输入时原核验应拒绝，不能删除断言或重写期望SHA绕过。已有本地完整包的使用者可按操作步骤上传配对ZIP及Notebook。

源码中的Windows绝对路径、封存父工程及数据准备依赖保持原样，用于来源审计；尚未验证跨机器一键重建。公开新增文件的离线核验：在仓库根目录执行 `python scripts/verify_c7_demo_publication.py --syntax`，只读取字节/语法，不导入板端程序或访问硬件。恢复完整数据和原工具链依赖后才能按原构建流程运行，不应把本快照当作已经重新构建的便携版。
